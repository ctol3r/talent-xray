## Procedure per search (Claude drives, owner pastes)

1. Create the search → paste the JD → Extract role intelligence → Intake
   → derive the search plan → **Generate strings** and **Compose from search
   plan**. Note the coverage card, QA warnings and the empty calibration
   panel.
2. Discover: run at least five strings across both engines; save at least
   five candidate results explicitly with names. Record yield per string
   (the ledger does this; copy the numbers here).
3. For each of five candidates: obtain the CV text lawfully (you paste;
   TalentOS never fetches); confirm extraction; **Analyze → copy artifact
   request** → fulfil in the Claude session → **Validate and import
   suggestions**; accept / dismiss / correct with notes.
4. Regenerate strings; record which terms moved and why (calibration
   panel); run the regenerated strings; compare yield before / after.
5. Prepare the reviewed shortlist; export.
