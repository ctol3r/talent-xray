## What shipped

- `src/lib/domain/query-normalization.ts` — one pre/post path around the
  untouched composer: `normalizeStringLabInput` (dedupe within and across
  vocabulary tiers, exclusions never negate a required term),
  `platformsForChannels` (profession-aware pruning from the strategy's
  channels; the three universal surfaces always stay), `fitToBudget`
  (32-term Google budget resolved by re-composing with a sliced OR group,
  never by truncation), `dedupeAcrossSurfaces`, `qaQuery` (parens, quotes,
  operators, empty groups, empty `site:`, budget), `channelCoverage`, and
  the orchestrator `prepareQueries` used by BOTH callers
  (`generateSearchStrings`, `composeDiscoveryQueries`). `dedupeTerms` moved
  here from `services/intelligence.ts` unchanged.
- `src/lib/domain/role-title.ts` — `normalizeRoleTitle`, no taxonomy.
- Migration `drizzle/0006_yield_ledger.sql` (generated by `pnpm db:generate
--name yield_ledger`): `search_query_runs`; `query_id` on
  `research_sources` and `candidate_source_evidence`; `qa_meta` plus the
  Wave B reserved columns `calibration`, `linked_requirement_ids` on
  `search_queries`. Applied only to disposable databases. No personal
  database exists on this machine; when Wave P creates one it initializes
  with 0006 already in the journal.
- `src/lib/services/query-yield.ts` — `recordQueryRun`,
  `queryYieldForProject`, `roleTitleYield` (live GROUP BYs).
- `src/lib/research/mock-discovery.ts` — watermarked mock provider, enabled
  only by `TALENTOS_DISCOVERY_PROVIDER=mock` (e2e).
- Discovery: `runDiscoveryAction` records a run (text, engine, result
  count); `saveDiscoveryResult` carries `queryId` only for verbatim runs;
  the panel tracks the selected string and shows an "edited" hint.
- String Lab: word-budget tag, part tag, QA badges, yield line per row,
  channel-coverage card, same-role rollup card, pruned-surfaces note.
  Discover: `· N saved` on the dropdown, "Yield for this search" card.
- Generate action note now reports pruned surfaces, dropped duplicates and
  splits.
- Docs: `DATA_MODEL.md`, `docs/BACKLOG.md` (String Lab items closed,
  follow-ups filed), `docs/DECISIONS.md` D-029.
